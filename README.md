# OBSERVER

Данное приложение помогает оператору SOC не только следить за аномалиями в сети, но и брать подсказки от LLM модели 
в режиме реального времени. В реальном времени оператор может взаимодейстовать с моделью

## Архитектура приложения

![Архитектура](/pictures/architecture.jpg)

### Бэкенд

Бекенд представляет из себя посредника, который принимает команды от фронтенд-клиента и передает их mcp-серверу, который тот в свое
время передает запрос локальной LLM-модели. Также, когда будет дан ответ от бекенда, то мы будем переделывать ответ под нужный
формат, также сохранять логи в базе данных, чтобы потом пользователь мог просмотреть краткую выжимку о логе от ИИ.
